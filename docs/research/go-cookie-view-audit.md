# Go cookie API views

This note records existing SDK semantics only; it adds no API, runtime behavior, or proof of authentication or protected-resource access.

| View                                      | What it exposes                                                                                                                                                                                                                                                                                                                                                                                    | Limitation                                                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `session.cookies(url)`                    | Decodes the Go `cookies.get` result as Effect `Cookies`, retaining `httpOnly`, expiry, `secure`, domain/path, and `sameSite` attributes. Go selects cookies for the target URL and exposes tracked attributes (`TlsClient.ts:587–624, 1007–1023`; `bridge/session.go:233–250`).                                                                                                                    | A target-URL Jar view, not the script-visible projection.                                                                            |
| `session.scriptCookies(url, setCookies?)` | A `document.cookie`-style string. The Go Jar operation is mutex-locked, rejects script changes to protected HttpOnly tuples, and excludes HttpOnly cookies from its returned list (`TlsClient.ts:1035–1049`; `bridge/session.go:286–363`).                                                                                                                                                         | An empty string does not prove the Jar is empty or that it contains no HttpOnly cookies.                                             |
| `session.exportCookies`                   | An Effect-valued property (yield it as `yield* session.exportCookies` in Effect code or run/await it through an Effect runtime; do not call it). It encodes the accepted Jar using `CookiesJson`: `name`, `value`, `domain`, `path`, optional `origin`, nullable integer `expires`, boolean `secure`/`httpOnly`, and optional `sameSite` (`TlsClient.ts:1051–1069`; `internal/Protocol.ts:22–40`). | A nonempty export proves only some Jar state—not the presence, freshness, or validity of a particular cookie, or application access. |

The existing `reviewedChallengeHandler` reads target cookies, evaluates its configured script, then reads them again. It returns retry evidence only when every configured cookie is nonempty and at least one value changed; this is not proof of clearance (`browser/ReviewedChallenge.ts:19–56`).
